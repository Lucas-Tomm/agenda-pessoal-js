# Agenda Pessoal

Aplicação web simples desenvolvida em **JavaScript puro** para organizar tarefas pessoais por data, horário, categoria e status.

O projeto foi criado com objetivo de **estudo e prática de JavaScript**, trabalhando manipulação do DOM, eventos, filtros, datas e armazenamento local sem uso de frameworks.

## Funcionalidades

* Criar tarefas
* Editar e excluir tarefas
* Marcar tarefas como concluídas
* Filtros por status
* Busca por título
* Categorias e prioridades
* Identificação de tarefas atrasadas
* Ordenação por data e horário
* Modo claro e escuro
* Salvamento automático com `localStorage`

## Tecnologias

* JavaScript
* HTML
* CSS
* LocalStorage

## Execução

O projeto pode ser aberto diretamente pelo `index.html` ou executado com um servidor local.

Exemplo:

```powershell
npx.cmd serve . -l 3000
```

Depois acesse:

```text
http://localhost:3000
```

Projeto desenvolvido para fins de estudo e portfólio.
